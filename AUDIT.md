# Audit

There is no current audit report in this repository, and deliberately so: a report goes stale
in weeks while the code keeps moving, and a stale one at the root of the repo reads as
authoritative to everyone who finds it.

- Superseded reports live in [`docs/archive/`](./docs/archive/README.md), with a note on how
  to read them and which of their claims are now wrong.
- For how the project actually behaves today, [`docs/README.md`](./docs/README.md) is the
  index, and the code is the source of truth.
